# Changelog

Todas las versiones notables de este proyecto se documentan en este archivo.

## [v0.1.0] - 2026-10-22

### Agregado
- Panel de administrador en React (store, sesión, login, registro de tienda, panel de marca, gestión de productos con atributos y alerta de stock bajo).
- Landing y catálogo con filtros.
- Carrito, checkout tributario (boleta/factura con DNI/RUC) y mis compras.
- Roles ADMIN y CLIENTE.
- Backend Spring Boot con MySQL dockerizado.
- Facturación electrónica SUNAT.

### Pendiente conocido
- Conexión completa del frontend con el backend.
- Registro de tienda y de cliente.
- Multi-tienda.
